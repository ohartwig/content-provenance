Frontend marking for media: the EU AI Act Article 50(4) disclosure, and the Content Credentials pin. Two marks, two meanings, two data sources — an asset can carry one, both or neither. EU icon driven by {origin} — this content is AI-generated/modified CR pin driven by {c2paStatus} — a C2PA manifest is attached Args: origin (string) required — AssetOrigin enum value fileUid (int?) optional — FAL uid; enables the inspector and the raw verification link. Without it the panel still renders from stored metadata. c2paStatus (string?) optional — manifest state; the pin shows unless this is empty, "none" or "unsigned" aiSystem (string?) optional — model name, appended after the EU icon compact (bool?) optional — basic EU icon, no wording (corner overlay) variant (string?) optional — "black" (default) or "white" for dark surfaces Which EU icon: ai_generated -> "AI GENERATED" the whole asset is AI-created ai_assisted -> "AI MODIFIED" human content altered by AI compact -> the basic icon, the variant the AI Office intends for pairing with your own label or an interactive layer The two labelled icons carry their wording inside the artwork, so no text is repeated beside them — only the model name is appended when known. They are wide (about 3.2:1), so height is set and width follows. Forcing them square would squash the lettering.
